Salesforce Match Endpoint Tester

Mit diesem Tool kannst Du das /api/salesforce/match-company Endpoint unserer Datenbank außerhalb von Salesforce prüfen. Gib einfach Deine Ziel-URL, das erwartete Token sowie die gewünschten Match-Felder ein – die Anfrage wird automatisch gebaut und ausgeführt.

Verbindung
Match Anfrage aufbauen

Alle Felder sind optional, allerdings muss mindestens ein Query-Feld gefüllt werden. Nutze den Bereich "Eigenes JSON" wenn Du vollständig selbst steuern möchtest, was gesendet wird.
